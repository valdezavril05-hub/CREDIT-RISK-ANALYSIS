# Credit Risk Analysis

## Project Overview
This project analyzes credit card client data to identify patterns associated with payment default and understand factors related to credit risk.

## Business Objective
Identify customer characteristics and payment behaviors associated with credit default to support better risk monitoring and preventive decision-making.

## Tools & Technologies
- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI
- DAX

## Dataset
UCI Default of Credit Card Clients Dataset.

- Total records: 30,000 clients.
- Target variable: `default.payment.next.month`.

## Key Findings
- Overall default rate: 22.12%.
- Payment status (`PAY_0`) showed a strong association with future default.
- The average credit limit was lower among clients who defaulted.

## Business Recommendations
Implement an early-warning system to identify customers showing signs of payment delays and enable preventive actions.

## Project Status
Exploratory data analysis and Power BI dashboard completed. Further validation and analysis are in progress.
